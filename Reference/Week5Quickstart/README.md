# CS110 Week 5 quick start

One theme. One visual recap. One small app. Finish the build by the end of Action 5B. You do not need a terminal or npm to finish this assignment.

Open the illustrated `CS110-Week5-Quick-Start.pdf` in this folder for the visual four-page route.

## Before Action 5A

1. Open your CS110 GitHub repository in VS Code or the approved editor. Find your Week 4 site and 3D view.
2. Open the [Week 5 guide](https://courses.addp2p.com/courses/cs110/week5). Choose a theme and read the five requirements.
3. Read [The package shelf: npm in plain language](https://courses.addp2p.com/assignments/cs110/week5/resources/npm-explained.html). Be ready to explain what a reusable package is. You do not need npm to finish this week's app.

## Day 1 / Action 5A

1. On the class whiteboard, sketch **newcomer → four-stop recap → first app action → visible result**.
2. Draft the recap in your own words with one picture or sketch per stop. Include the package-shelf analogy in the tools-and-code stop.
3. Start the themed app in your existing site or a linked `Week5` folder. Connect HTML, CSS, and JavaScript. Link your Week 4 3D view. Commit and push to GitHub.
4. Submit the 5A evidence in [Canvas Action 5A](https://sbccd.instructure.com/courses/66804/assignments/1897212).

## Day 2 / Action 5B

1. Finish one JavaScript control with a visible result. Adapt one part of the 3D view to fit your theme.
2. Let a peer follow the recap and use the app. Trace the click, code, and result on the whiteboard. Fix one unclear part.
3. Explain your theme, app, analogy, and revision in the class Discord. Commit and push the revision. Submit the 5B evidence in [Canvas Action 5B](https://sbccd.instructure.com/courses/66804/assignments/1897213).

## Final return

Check the GitHub and site links. Download the theme selection receipt from the Week 5 guide. Submit the links and receipt in the [weekly Canvas assignment](https://sbccd.instructure.com/courses/66804/assignments/1897211). The receipt records your choice, not completion.

## Optional / Instructor Hello npm demonstration

A terminal is a text window for typing instructions for a computer. npm is a tool developers can use there to bring shared code into a project. In the tiny demonstration, a package called `dayjs` helps format today's date.

Watch for three moments if your instructor shows it: the project lists the package in `package.json`; npm brings it in; the program uses it to print a greeting and date. The downloadable ZIP contains these files for a guided walkthrough.

For Week 5, understand the idea. You do not need to open a terminal, install a package, make an npm account, publish a package, or set up GitHub Actions.
