My CS110 Newcomer's Guide

This guide explains what I have learned so far and how an idea can turn into something people can actually use.

From an idea to something people can use

Computer science is not only about writing code. It is also about asking questions, being creative, understanding people, and using tools to turn ideas into working experiences.

01

Mindset

How we learn

I learned that questions, creativity, personality, and support all affect how I learn. One important part of learning computer science is being willing to try something, make mistakes, and change my approach when something does not work.

Newcomer question: What can I change if my first approach does not work?
02

Story to Screen

How an idea becomes a UI

Before creating a website or application, I need to think about the audience, the user's need, and the type of experience I want to create.

Visual

Logical

03

Tools + Code

How the app works

HTML creates the structure, CSS controls the appearance, and JavaScript adds behavior. VS Code is where I can work on the project, while Git and GitHub help me save and share changes.

HTML CSS JavaScript VS Code Git GitHub 3D
04

Network + People

How it reaches others

A website has to travel through a network before someone can use it. A browser connects through a name server to find the site server. GitHub and Discord can also help people work together.

Browser → Name Server → Site Server
